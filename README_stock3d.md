# stock3d.py — A股三维数据拉取（技术面 / 基本面 / 消息面）

> 单文件 CLI。参考 `caiwu/scripts/fin.py` 的分段架构与踩坑结论，但**完全独立**，不 import 它。
> 全部输出为**中性事实与数值**，不含买卖建议、不做综合评分、不构成投资建议。

```
python stock3d.py pull 002463.SZ 沪电股份      # 三维全出（默认子命令）
python stock3d.py pull --pool <持仓文件>       # 从持仓/自选文件读标的
python stock3d.py tech 002463.SZ               # 只跑技术面
python stock3d.py fund 002463.SZ               # 只跑基本面
python stock3d.py news 002463.SZ               # 只跑消息面
python stock3d.py pull 512890.SH 000300.SH     # ETF/指数：技术面+消息面，基本面标"不适用"
```

**交付物只有一个 JSON**：`data/stock3d_<YYYYMMDD>.json`。不产出 md，也不产出分维 json。

## 一、参数

| 参数 | 适用 | 说明 |
|---|---|---|
| `tokens` | 全部 | 标的，可多个。支持 `002463.SZ` / `002463` / `沪电股份` 三种写法 |
| `--pool FILE` | 全部 | 持仓/自选文件；自动识别「证券代码」列，兼容 `caiwu\持仓数据.md` 的多列格式 |
| `--out DIR` | 全部 | 落盘基目录（默认 `<脚本目录>\data`） |
| `--date YYYY-MM-DD` | 全部 | 目标交易日（默认今天） |
| `--no-cache` | 全部 | 忽略日K缓存强制重拉 |
| `--debug` | 全部 | 打印调试信息（含落盘绝对路径） |
| `--rt` | `tech` / `pull` | 附加盘中分时、五档、分笔 |
| `--kline-source` | `tech` / `pull` | 强制指定日K来源 `hithink/em/tx/sina`（降级演练用） |
| `--top N` | `news` / `pull` | 每标的消息面保留条数（默认 30） |
| `--skip A,B` | 全部 | 跳过重活模块：`peers` / `valuation-history` / `shareholders` / `moneyflow` / `auction`。默认全跑 |
| `--kline-max N` | 全部 | 日K最多 N 根；`0`（默认）= 按源能力取最长 |

## 二、三维各取什么

**分工原则（勿混）**
- **基本面 = 财报口径数据**：三张报表、报告期指标、估值。**不放公告、不放新闻。**
- **消息面 = 公告与资讯**：巨潮公告、7×24 快讯、异动原因、热度榜、龙虎榜。
- 需要「公司发生什么事」看消息面；需要「公司赚多少、值多少钱」看基本面。

### 技术面
- **快照**：`market.snapshot`（个股/指数，复数 `--thscodes`）；ETF 走 `fund.snapshot`（**单数** `--thscode`）。
- **日K 降级链（顺序即优先级）**：hithink → 东财 → 腾讯 → 新浪。
  前复权源优先；新浪为**不复权**，放最后兜底，落盘会标注实际生效来源与复权口径。
- **指标**：MA5/10/20/30/60、60日高/低/分位、20日高/低、量比、MACD、KDJ、RSI14、BOLL(20,2)、MA10/MA20 乖离、近10日涨幅。
- **中性事实标注**：均线排列、乖离阈值、近5日 MACD 金叉/死叉、RSI 区间、BOLL 位置、放量/缩量、60日分位档位。
- **公司行动**：近 2 年分红送转/除权除息（个股）。
- **扩展块**（对齐清单新增）：
  - `levels`：区间/近1年/近60日平台/近20日高低、MA120、MA250、换手率、振幅、量比、涨停跌停价
  - `weekly` / `monthly`：日K聚合的周线与月线（MA5/10/20/60周、MA5/10/20/60月）
  - `gaps`：未回补缺口（方向、缺口下沿、幅度、规则判定类型）
  - `volume_price`：近 5/10/20 日涨跌天数、涨跌均量、涨跌量比 + 量均线 MA5/10/20/60
  - `divergence`：MACD 顶/底背离（规则判定，附价格与 DIF 变化值）
  - `cross_state`：MA5/MA10 与 KDJ 金叉死叉、MACD 零轴位置
  - `turnover`：日/5日/10日换手率 + 反推的流通股本
  - `auction`：集合竞价（竞价价、涨跌幅、量、量比、未匹配量、换手率）
  - `limit_board`：当日涨停/炸板池命中情况（封单金额、连板数等）
  - `chips`：**筹码代理**说明（真实筹码分布源不可达，见 unavailable）
- **成交量单位已归一化**：hithink/新浪为「股」，东财/腾讯为「手」，代码统一 ×100 折算成股——
  否则换手率与量能均线会整体差 100 倍。

### 基本面（仅个股；ETF/指数显式标 `applicable: false`）
> 只放**财报口径**数据。公告与事件不在此维，见消息面。
- **双轨报表**：季报 12 期（`--period quarterly --limit 12`）+ 年报 5 期（`--period annual --limit 5`），三大报表各取。
- **报告期指标**：`financials.indicators` 最近报告期，返回空自动回退上一期（最多回退 2 次）。
- **派生（pandas 宽表）**：营收/单季营收/归母净利、毛利率、净利率、ROE、资产负债率、经营现金流÷净利润，以及营收同比、净利同比、毛利率同比(pp)。
- **估值快照**：PE(TTM)/PE(MRQ)/PB(MRQ)/PS(TTM)/PCF(TTM)。
- **口径说明**：季报为**年初至今累计**（Q1=Q1, Q2=H1, Q3=9M, Q4=全年），单季值由同财年相邻累计期相减；同比取同一财季的上一财年。
- **扩展块**（对齐清单新增）：
  - `statements_detail`：东财 F10 完整三表明细（季报 12 期 + 年报 5 期）。白名单科目：货币资金、
    交易性金融资产、应收票据及应收账款、应收账款、存货、固定资产、在建工程、商誉、短期借款、
    长期借款、应付债券、一年内到期非流动负债、流动资产/负债合计、资产/负债/归母权益总计；
    销售/管理/研发/财务费用、营业利润、利润总额、所得税、净利润、归母净利润、**扣非归母净利润**、
    基本每股收益；销售商品提供劳务收到的现金、经营/投资/筹资现金流净额
  - `derived`：单季环比（用单季值，不是累计值相除）、单季序列与单季同比、3 年 CAGR（年报轨 2022FY→2025FY）、
    ROE 序列、资产负债明细（类现金、有息负债、类现金/有息负债、流动比率、速动比率）、扣非与非经常性损益、
    四项期间费用率、应收账款/存货周转天数、营收现金含量、ROIC
  - `business`：证监会行业 + 东财三级行业 + 主营构成（按产品/按地区：收入、占比、毛利率）
  - `shareholders`：十大股东/十大流通股东（含较上期变动）、股东户数与集中度、机构持仓及机构家数、
    北向持股、股权质押、分红送转、业绩预告、限售解禁、两融序列、机构调研
  - `peers`：同行业按总市值 Top10（剔除自己）+ 行业均值（PE/PB/PS/ROE/毛利率/净利率/营收同比）
  - `valuation_history`：自建 PE-TTM 与 PB 的 3/5 年分位（近似口径，附当前值、区间高低、覆盖年限）

### 消息面
- **公告（本维的公告主场）**：巨潮资讯按 `stock=<code>,<orgId>` 精确过滤，窗口 **近 30 天**，按「业绩与财报 / 股权激励 / 股东与股本 / 分红与权益 / 融资与投资 / 经营与合同 / 公司治理 / 其他」规则分类，并给出事件分类汇总 + 逐条明细（含距今天数）。
- **快讯池（7 源，全市场取一次供全部标的过滤）**：财联社电报（签名 roll，可翻页）、财联社热榜（SSR）、华尔街见闻（a-stock+global）、金十、同花顺、新浪 24h、东财 7×24。
- **匹配关键词**：股票全称 + 名称前 4 字（≥5 字时）+ 6 位代码。
- **官方端点**：当日异动原因（`anomaly-stock`）、当前热股榜（`hot-stock --period day`）、近 30 日热榜排名序列（`hot-stock-trend`）。
- **龙虎榜**：近 30 天东财 datacenter 按 `SECURITY_CODE` 单次过滤（含上榜原因与净买额）；当日机构专用/游资席位来自 `dragon-tiger --board-type org|hot_money`。
- **中性事实标注**：命中条数、来源分布、最新一条、公告条数、当前热榜排名、30 日热度趋势、30 日上榜次数与净买合计。
- **扩展块**（对齐清单新增）：
  - `notices` 事件分类扩展为：**风险公告**（问询/立案/退市/下修/诉讼/处罚）、**资本运作**（并购/重组/定增/
    可转债/股权激励）、**股东动作**（减持/增持/回购/质押/解禁）、分红与权益、业绩与财报、经营与合同、公司治理
  - `contracts`：重大合同/订单/扩产/新产品/技术/专利（**公告标题级，无结构化金额**，字段内已标注）
  - `risk_notices`：风险类公告单列
  - `policy_proxy`：行业政策**弱代理**（行业名 + 政策关键词过滤当日快讯池，非官方政策库）
  - `moneyflow`：两融余额序列、北向持股存量、机构调研（近 30 天次数与机构名单）、
    龙虎榜买卖前五席位明细（含「机构专用」标识）、成交额/换手率 TOP100 名次

## 三、交付格式与落盘

```
data/
  stock3d_<YYYYMMDD>.json   唯一交付物：当日全部标的的三维数据
  history/<thscode>.json    日K缓存（内部用，按目标日校验，换日自动重拉）
```

`stock3d_<YYYYMMDD>.json` 结构：

```jsonc
{
  "tool": "stock3d", "schema_version": "1",
  "target_date": "2026-09-11", "generated_at": "...", "session": "非交易时段（当日已定格）",
  "dims_run": ["tech", "fund", "news"], "node_calls": 19,
  "flash_pool_sizes": {"财联社电报": 100, "...": 0},   // 各快讯源条数（跑消息面时）
  "resolves": ["002463 -> 002463.SZ (沪电股份, a-share, code)"],
  "unresolved": [],                                   // 解析失败的输入
  "failures": [{"dim": "tech", "code": "...", "reason": "..."}],
  "prev_generated_at": null,
  "symbols": [
    {
      "code": "002463.SZ", "name": "沪电股份", "type": "stock", "asset_type": "a-share",
      "status": {"tech": {"mark": "OK", "note": "..."}, "fund": {...}, "news": {...}},
      "tech": { "snapshot": {...}, "kline": {...}, "analysis": {...}, "tags": {...},
                "corporate_actions": [...], "sources": {...}, "degrade": [...] },
      "fund": { "applicable": true, "indicators": {...}, "quarterly": [...], "annual": [...],
                "valuation": {...}, "tags": {...}, "sources": {...}, "degrade": [...] },
      "news": { "flash": [...], "notices": {...}, "anomaly": [...], "hot": {...},
                "lhb": {...}, "seats": {...}, "tags": {...}, "sources": {...}, "degrade": [...] }
    }
  ],
  "note": "全部输出为中性事实与数值，不含买卖建议，不构成投资建议。"
}
```

- `status` 逐标的记录各维成败（`OK`/`SKIP`/`FAIL`/`DEGRADE`），与 `tech/fund/news` 内部的 `sources`、`degrade` 对应。
- **部分重跑会合并**：`python stock3d.py tech 002463.SZ` 只更新该标的的 `tech`，文件里其它标的、其它维度原样保留（`prev_generated_at` 记录上一次生成时间）。

## 四、铁律与已知边界

**数据源确实拿不到的项（每维 `unavailable` 显式列出，不静默缺失）**

| 维度 | 拿不到的项 | 原因 |
|---|---|---|
| 技术面 | 筹码分布/筹码峰/集中度、获利盘/套牢盘、市场平均持仓成本、筹码迁移 | 东财 cyq 接口 404 且 push2 拒连 |
| 技术面 | 日线+60 分钟多周期共振 | 腾讯 m60 与东财 klt=60 实测均不可达 |
| 技术面 | 价格形态命名（底部/顶部/整理） | 属主观形态识别，本工具只输出事实性价位结构 |
| 基本面 | 产能/产量/销量/市场占有率 | 无结构化数据源 |
| 基本面 | 行业景气度（行业 PMI 等）、DCF/分部估值、行业地位梯队 | 无数据源 / 属建模与判断 |
| 基本面 | 大股东质押平仓线 | 不对披露，仅有质押比例与市值 |
| 消息面 | CPI/PPI/PMI/社融等宏观指标 | 未接宏观源（caiwu `fin.py macro` 有） |
| 消息面 | 行业高频数据、地方政策结构化数据、大宗商品期货、美股同业映射 | 无数据源 |

**铁律**
1. **stdout 只输出 ASCII**：PowerShell 管道会把 UTF-8 中文按 GBK 解码成乱码，因此状态行一律剥离非 ASCII 字符，中文内容只进文件。
2. **失败绝不伪装**：任何源失败都落显式 `[FAIL]`/`DEGRADE` 与原因；指标窗口不足一律 `null`，**严禁置 0 冒充数据**。
3. **名称⇔代码双向一致**：中文名必须精确匹配同名的 thscode，否则报错不取数（`AGENTS.md` 铁律）。
4. **不适用 ≠ 失败**：ETF/指数的基本面、非个股的热榜/席位/异动标 `N/A`，不计入降级。

**已知边界（实测）**
- **日K长度受源限制，无法保证全历史**：新浪 `datalen` 上限 1023 根、腾讯约 800 根，
  东财可不限根数但常被 IP 级限流；hithink 三个 history 端点的窗口上限实测为
  基金 <5 年、指数 5 年（7 年静默返空），故统一夹到 1800 天（≈4.93 年）。
  降级时 `kline.coverage` 会记录实际覆盖区间，样本不足的长周期指标落 `null` 并在 `unavailable` 注明。
- `market.history` 服务端存在 `raw_kline_daily` 表缺失故障（`CLI_INTERNAL_ERROR`），已做**三级重试**（常规 → 2s 重试 → `--output` 落盘重试），仍败即降级到东财/腾讯/新浪。
- 东财 `push2his` 族会出现 **IP 级时段性拒连**（本次实测所有镜像同时 `RemoteDisconnected`，同一请求几分钟后可恢复），已做 host 轮换 + 指数退避。
- 东财 K 线偶发**忽略 `lmt` 返回全量历史**（实测 3894 根），代码统一截断到最近 130 根。
- 东财 7×24 快讯的行键在 `list` / `fastNewsList` 之间变动（实测为 `fastNewsList`），且 `code="1"` 表示成功；两个键都收，空数组才报 FAIL。
- 巨潮公告必须带 `orgId`（`stock=<code>,<orgId>`），仅传代码会静默返回 0 条；代码已内置 `topSearch` 取 orgId。
- **公告窗口不能设太窄**：窗口曾设为「当日 → 近 7 天」，结果把 002463 在 9 天前（2026-09-02）的一条公告切在窗口外，而近 30 天实际有 15 条 → 输出成「无公告」。现固定为近 30 天单次拉取。
- 财联社 `rn` 上限 50，超过会「errno=0 但数组为空」地静默失败。
- 东财快讯 `req_trace` 必填，漏掉返回「code=0 + 空数组」的静默失败。
- 新浪 `hq.sinajs.cn` / 日K 必须带 `Referer: finance.sina.com.cn` 且按 GBK 解码。
- 北向资金沪深港通日度净买入自 2024-08 起停止披露，消息面以龙虎榜席位与热榜热度替代观察。
- 估值端点只有当前快照、无历史序列，故不做估值历史分位。

## 五、维护须知

- 单文件，按 `# ===== [SEC-nn] 标题 =====` 分段；`Select-String -Path stock3d.py -Pattern '^# ====='` 可列出骨架。
- 改完必须跑：
  ```powershell
  python -c "import ast,io; ast.parse(io.open('stock3d.py',encoding='utf-8').read())"
  python stock3d.py --help
  python stock3d.py tech 002463.SZ --kline-source tx   # 降级链演练
  ```
- 依赖：`requests`（缺失时消息面降级 urllib）、`pandas`（基本面宽表，缺失时该维报 FAIL 并给安装提示）。
- 刻意保留的分离：`num()`（缺失→`None`，数据口径）与 `_f()`（缺失→`0.0`，json 数值契约，其返回值直接参与数值比较）——勿统一。
