# webui — aiplan 的浏览器控制台

> 把 `aiplan.py` 的 CLI 能力搬到网页：运行研判、看报告、查历史、改配置、看大盘快照、按模块荐股。
> **零第三方依赖**（只用 Python 标准库），**不修改** `aiplan.py` / `pan.py` / `stock3d.py`。
> 报告仍由大模型生成，**不构成投资建议**。

## 一、启动

```powershell
python main.py                         # 推荐：统一入口，默认 http://127.0.0.1:8765，自动开浏览器
python main.py webui --port 9000       # 换端口
python main.py webui --no-browser      # 不自动开浏览器
python main.py webui --host 0.0.0.0    # 局域网监听（口令见下节，源码内无默认值）
cd src; python -m webui --port 9000    # 等价写法：直接跑包
```

也可以直接双击根目录的 **`启动WebUI.cmd`**（脚本内含 Python 缺失提示与端口占用提示），
或执行 `scripts\serve.cmd 9000` 指定端口。
需要让手机或其它局域网设备访问时，直接双击 **`启动WebUI局域网.cmd`**；首次运行会请求一次管理员权限，
添加仅允许本地子网访问 TCP 8765 的防火墙规则。启动窗口会打印桌面与手机版局域网地址：手机直接打开 `/m`，
其它设备也可打开根地址；登录页输入启动窗口打印的访问口令，从 `/m` 发起的登录完成后会回到手机版。

> 目录位置：控制台代码在 `src/webui/` 包内（路由 `webserver.py`、路径真源 `paths.py`、
> 荐股 `pick.py` / `pick_run.py` …，模块地图见 [ARCHITECTURE.md](ARCHITECTURE.md)），
> 前端是 `static/js/{core,ui,views}` 的原生 ES 模块，**无构建步骤**，改完刷新页面即生效。
> 模块化之后入口从 `/app.js` 换成 `/js/main.js`，旧页面缓存会 404，请按 Ctrl+F5 强刷一次。

默认只监听 `127.0.0.1`；非回环地址会强制密码登录，口令按 **`--password` → 环境变量 `AIPLAN_WEBUI_PASSWORD` → 本地 `config/webui配置.json` 的 `密码` 字段 → 随机生成** 的顺序解析，成功后通过 Cookie 保持 7 天。默认口令不写进源码，避免公开仓库等于公开口令；想固定手机登录口令，就在 `config/webui配置.json` 写 `{"密码": "你的口令"}`，该文件已在 `.gitignore` 内。局域网入口仍只应在可信网络临时使用，**不要**暴露到公网。

## 二、九个页面

桌面根地址和手机专用入口 `/m` 都默认进入**总控台**。手机版复用同一套九页数据与操作，隐藏桌面侧栏，
底部常驻「总控台 / 研判 / 报告 / 持仓 / 更多」，“更多”内含历史、自选、荐股、模型配置和大盘快照。

| 页面 | 能做什么 |
|---|---|
| **总控台** | 持仓股 / 自选股**卡片**（每只一张：行情与持仓指标、带计划价格线的分时小图、触发徽章与操作提示；点卡片打开该股最新报告，卡上有「研判」「K线」）；卡区右上角****进入页面自动刷一次实时价**（8 秒内反复进出只读本地）；自动刷新开关 + 5 档间隔**（10s / 30s / 1min / 3min / 10min，默认 30s、默认关闭、记住设置；只在交易时段跑，页面在后台自动暂停，连续失败自动退避）——盘中没开自动刷新会在页面顶提示；价格线被触发时卡片出徽章；到价提醒进**消息队列**——服务端落盘 `data/ai/alerts.jsonl`（保留最近 500 条），顶栏铃铛显示未读数（任何页面可见，点开即已读），控制台队列卡可清空；卡片上的价位是**一个精确价 + 手数**（买点/减仓用该动作股数、止损用可用持仓、止盈用持仓总数，1 手 = 100 股），止盈点只显示现价上方最近的一个。价格默认本地口径（持仓文件市价 / stock3d 缓存），点「刷新实盘价」用一次东财批量请求换实时价。下方还有系统状态（账户、数据新鲜度、模型与环境）与待接入模块占位 |
| **运行研判** | 明面只有 **时段 + 标的代码**（填完就能跑）；右侧一行按钮：**批量研判持仓**（对持仓文件里每只标的依次跑，单只失败不中断，结束给成功/失败汇总表；确认框会列出标的、提示缓存缺失与费用，并可选择「跳过复核省一半」）；`交易日 / profile / 抓数条数 / 事实包预算` 与 `--no-review / --debug / 覆盖模型与 Key` 分别收在两张卡片的「高级选项」里，常用开关只留 `--dry-run`（只看不花钱）和 `--no-fetch`（复用已有数据）。输出实时回显、可中断；跑完自动跳报告。**运行前会就地预检**：开着「复用已有数据」而选中标的又不在最新 stock3d 缓存里时，代码框下方会直接给出警告；失败后会额外给一段中文**诊断**（把退出码翻译成原因与下一步），因为 aiplan 的 stdout 中文会被转成 `?` |
| **报告** | 结构化面板（卡片顺序：**K 线与关键价位 → 交易计划 → 关键价位** 置顶，下面是实盘复核与情景树等）：**实盘复核**（当前时段 / 实盘价与口径 / 每条计划是否触发、距触发多远 / 止损·支撑·压力·目标对现价的判定 + 模型判定时用到的量价数据；可「刷新实盘价」，并可点一次模型生成**当前时段策略点评**（「放量 / 缩量 / 板块资金」这类文字条件由模型拿背景数据自己判，状态只有「已满足 / 未满足」，不推回人工确认），结果落 `data/ai/plancheck/`，同报告复用上次点评不重复花钱）/ 结论头部 / 仓位条 / **情景树 + 综合评价**（脚本按情景概率机械汇总出多空倾向与评分）/ 关键价位 / **K 线图（标注支撑·压力·止损·目标与现价）** / 交易计划（价位直接给**精确数值并附该价位的依据**）/ 风险 / 机械风控校验（通过·违规·提示）/ 复核质询 / 上次计划回检 / 数据依赖 / 运行元信息。另有完整 Markdown（带章节目录）与原始 JSON 树，可下载 `.md` |
| **历史与复盘** | 计划记录与报告归档**合并成一张表**（它们本就是同一份产出）：时间、时段、标的、方向、置信度、校验、模型、费用、复盘、报告。只有报告、没有计划记录的行会标「无记录」。每行一个**删除**按钮，弹窗让你选「只删记录」还是「记录和报告都删」（报告移入回收站）。下方是**回收站**：列出所有被移走的历史快照与报告文件，点「恢复」即可搬回原位 |
| **自选股** | 独立的自选清单（存 `自选股.md`，管道表格）。填 6 位代码即可加入，名称留空会自动用行情缓存里的名称补全；表格显示现价、涨跌幅与「已缓存 / 未抓数」状态。每行可以一键**研判**（填进运行页）或**删除**；整页可**批量研判自选**；也能直接编辑原文。自选股会自动出现在运行页的「选择」列表里 |
| **持仓 / 账户** | 解析后的持仓表（余额、可卖、冻结、成本、现价、市值、盈亏、占总资金、回本需涨）+ 账户配置表单编辑（含 **ETF 专享费率** `ETF_*` / 兼容旧前缀 `ETC_*`，每项带口径提示）+ 持仓文件原文编辑 + **一键从已登录同花顺同步**（资金/持仓/当日成交，后台任务可中断；运行前确认未保存编辑；同步日志框运行时自动展开、结束后收起） |
| **模型配置** | profile 卡片（研判 / 复核两档、温度、max_tokens、参数）、provider 表（Key 仅显示掩码与来源）、一键 `check-model` 自检（可先在下拉里挑 profile）、配置原文编辑 |
| **大盘快照** | 顶部是**大盘走势预测**（点按钮用当前 pan 快照调一次模型，输出方向 / 置信度 / 多空评分 / 情景树 / 关键点位 / 关注板块 / 风险与数据依赖，结果落 `data/ai/market/`，可重复生成）。下方读 `data/pan/` 最新一份 `latest_<phase>.json`：指数与量能、情绪与广度（涨跌分布、连板梯队与名单）、资金（主力 / 南向 / 两融 / 行业资金 TOP10）、板块轮动、个股榜、数据源状态、降级清单 |
| **荐股** | **先筛选板块，再跑**（默认不选）。行业：31 个一级行业 → 展开看二级细分（如 电子 → 半导体 186 / 消费电子 99 / 光学光电子 99 …），可只勾其中几个；概念：504 个概念按 16 个主题分组（AI与算力 / 半导体与电子 / 医药与生物 / 军工与安全 / 新能源与电力 / 打板与热度 / 风格与因子 …），组内勾选 + 关键词搜索；另有「全选本页」（按当前搜索范围全选：行业一次最多 31 个、概念受 120 个上限约束会先提示）与「热度前 10」（一级行业热度前 5 + 概念热度前 5）。**模块是单选**（短线 / 波段 / 中线 / 长线 四选一，切换即换权重），明面只留**模块**与**每板块候选**，`候选上限 / 事实包预算 / profile / 模型与 Key / 排除规则` 在「高级选项」里。只抓选中的板块 → 本地**机械打分**（板块 0-100，个股按模块换权重）→ 中性事实包交给模型**点评一次** → 页面给出总评、**模块 × 板块矩阵（行业 / 概念）**、两张板块评估表（带行情口径与入池数）、每模块候选表（含精确买点 / 止损 / 目标位及依据）。候选行可一键「加入自选 / 研判 / K 线」，结果落 `data/ai/pick/<日期>/`，可下载 Markdown 或删除（进回收站） |

## 三、数据与写回策略

- **只读复用**：后端 `import aiplan`，持仓解析、账户校验、报告读取都走 aiplan 自己的函数，口径与 CLI 完全一致。
- **自选股与持仓分开**：`自选股.md` 是纯关注清单，只用于挑标的与批量研判，不参与仓位与费用测算（那只看 `持仓数据.md` 与 `账户配置.json`）。
- **写回白名单**：只有这三个文件能通过网页保存——`持仓数据.md`、`账户配置.json`、`模型配置.json`。
- **荐股只读行情**：荐股页除「加入自选」外不写任何配置；产物单独落 `data/ai/pick/<YYYYMMDD>/`，**不进** `plan_log`、不参与复盘；删除时移入回收站。
- **回收站 7 天过期**：`data/ai/.trash/` 下的条目（报告、计划历史快照、荐股结果）**超过 7 天自动真删**，服务启动时清理一次、打开历史页时惰性清理（同进程 30 分钟最多扫一次），也可以点「清理过期」立即执行。页面逐条显示「剩余天数」，≤2 天标黄。**真删不可恢复**，需要留档请先搬回原位。
- **内容无变化就不写**：提交内容与文件一致时跳过，不写盘也不产生备份。
- **真改动了才落盘**：先备份成同名 `.bak`，再按**原文件的换行风格**（LF / CRLF）、BOM、结尾换行写回，尽量不制造无意义的 diff。
- **先校验后写入**：JSON 必须合法；账户要求「总资金」> 0；模型配置要求 `providers` / `profiles` 非空。校验失败一律拒绝并且不碰原文件。
- **任务产物定位**：跑完按 `data/ai/<YYYYMMDD>/` 里 `HHMMSS_<phase>.json` 的 mtime 取本次最新；`--dry-run` 则定位 `.factpack.md`。失败（退出码 3）时报告照样落盘并在页面打开，标注 `[FAIL]`。
- **中断**：Windows 下用 `taskkill /F /T` 结束整棵进程树，不会留下 `pan.py` / `stock3d.py` 残留进程。
- **同花顺同步**：`holdings_sync` 任务只读取已登录客户端；校验通过后更新持仓文件、账户总资金、`data/user/交易台账.md` 和 `data/holdings/ths/snapshots/`。预览、非交易日跳过成交查询、客户端未登录或校验失败时不写业务文件。若出现复制验证码，任务会暂停并在页面弹出图片，人工填写后继续；验证码不会写日志，也不做自动识别。

## 五、控制台为什么不再是乱码

`aiplan.py` 的既有铁律是「stdout 只出 ASCII，中文一律进文件」，直接看命令行会满屏 `?`。网页端跑的是 `src/webui/run_aiplan.py` 这个包装器：它在导入 aiplan 之后，只把 `aiplan._ascii()` 换成恒等函数、并把标准输出切到 UTF-8，**没有改动 `aiplan.py` 一个字**。所以网页控制台能看到完整中文（事实包章节名、dry-run 提示、失败原因等）；你直接 `python aiplan.py ...` 的行为保持原样（`python main.py aiplan ...` 会自动走这个包装器）。

## 六、已知边界

- **控制台里的中文会显示成 `?`**：这是 `aiplan.py` 的既有铁律（stdout 只出 ASCII，中文一律进文件）。网页如实转发、不做猜测还原，但会在下面补一段中文**诊断**说明失败原因与下一步（例如退出码 4 = 选中标的不在本地数据里）。**报告、配置、页面文字本身都是正常中文**。
- **退出码 4 最常见的两种情形**：① 开着「复用已有数据」但该标的还没抓过（缓存里没有）→ 警告会提前提示，关掉开关重跑即可；② 代码写错或该标的数据源拿不到 → 确认代码是 6 位（如 `002463`）或 `002463.SZ` 形式。
- **退出码原样透传**：`0` 正常 ｜ `2` 参数/配置错误 ｜ `3` 模型调用失败 ｜ `4` 数据缺失。页面按退出码显示「完成 / 失败」，不会把失败伪装成成功。
- **`check-model` 可能很慢**：如果 profile 的研判档是推理模型（如 `glm-5.3`），ping 会先花 reasoning token，可能耗时数分钟；换 `*-全闪` 档自检通常 1～2 秒。
- **一次只研判一只标的**：沿用 aiplan 的单标的约束，本页不做批量与定时。
- **大盘走势预测是模型产物**：点一次按钮 = 一次真实模型调用（产生 token 费用）。它复用所选 profile 的「研判档」，结果只落 `data/ai/market/`，**不写进 `plan_log`**，也不参与个股报告。
- **K 线图依赖本地缓存**：读 `data/history/<thscode>.json`（前复权日K，pan.py / stock3d.py 抓数时落盘）。缓存里没有该标的时，卡片会提示先跑一次抓数。
- **综合评价与精确价位是确定性渲染**：综合评价只是按情景概率机械汇总，不会再让模型二次判断；计划里的价位依据取自同一份报告的「关键价位」，按 2% 邻近匹配，匹配不到就只显示数值。
- **任务记录在内存**：重启服务后，运行页的历史输出清空（落盘的报告与 plan_log 不受影响）。
- **荐股固定花一次模型调用**：跑之前先抓板块与成分股（不花钱），最后把机械榜交给所选 profile 的**研判档点评一次**（不调复核档）。模型失败时**机械榜仍然落盘**，页面会明确标注「本次没有模型点评」，不会掩饰。
- **荐股机械分不是收益预测**：板块分 = 动量 35 + 资金 30 + 广度 20 + 量能 15；个股分按模块换权重（短线偏动量+资金，中线偏估值+流动性，长线偏估值+市值+长期趋势），所有「分位」都在**本次候选池内**计算。缺少的字段不计分（按可用权重归一），不会拿 0 顶替。
- **荐股只依赖东财（纯 HTTP，不调 node）**：板块行情、一级行业成分、概念成分都走东财 push2。板块行情与一级行业成分会缓存（内存 30 分钟 + 磁盘 `data/cache/pick_*.json` 6 小时，点「刷新板块」强制重取），没缓存时展开一个行业约 0.3-2 秒。东财不可用时：行业行情自动回退成**成分股聚合**（涨跌幅中位数 / 主力净占比均值 / 成交额合计 / 涨跌家数），概念取不到就跳过，降级项逐条写在页面与产物里。
- **荐股没有财务数据**：本轮不抓 ROE / 分红 / 财报，只有行情与估值（PE / PB）。长线模块因此只用估值分位 / 市值 / 动量，模型被要求在「降级与不确定性」里写明这一点。
- **荐股不再包含指数**：「指数」这个板块类型已移除（指数只在「大盘快照」页展示）。历史产物里若还有指数列，页面仍能打开查看。
- **概念主题是本地关键词表**：16 个主题 + 「其他」（实测 504 个概念里落「其他」的只有 11 个）。未命中的概念照样能用搜索找到并勾选；勾选上限 120 个（每个概念 1 次请求）。
- **只抓选中的板块**：未选的一律不拉取；候选总数超过「候选上限」时按板块热度从高到低截断。
- **模块单选**：一次只跑一个模块（短线 / 波段 / 中线 / 长线），换模块就等于换打分权重；产物里的 `参数.模块` 始终只有一个值，页面只出一张候选表。
- **全选会很大**：全选 31 个一级行业会连带全部二级细分（实测合计约 128 个细分板块），抓取更久、候选池更大；页面会先弹确认，建议同时把「候选上限」调小。
- **中途取消**：在抓板块 / 抓成分阶段取消会立刻停止且不落盘；如果已经进入模型调用，会在模型返回后丢弃、同样不落盘（页面状态显示「已中断」）。

## 七、排障

| 现象 | 处理 |
|---|---|
| 端口被占用 | 启动信息里会给实际端口（8765 起自动顺延 20 个）；也可 `--port` 指定 |
| 页面提示「账户配置不存在」 | 先跑 `python aiplan.py init-account`，并填真实「总资金」 |
| 报告页空白 | 先跑一次 `python aiplan.py post --code 002463.SZ --no-fetch --dry-run`（零成本）确认事实包能生成 |
| 大盘快照无数据 | 先跑一次 `python pan.py post`，页面读的是 `data/pan/<日期>/latest_post.json` |
| 想还原误改的配置 | 同目录 `.bak` 即保存前的原文件，直接改名覆盖即可 |
| 想找回删掉的报告 | 「历史与复盘」页最下方的**回收站**里点「恢复」；或手动把 `data/ai/.trash/<日期>/` 里的文件搬回 `data/ai/<日期>/` |
| 批量研判中途想停 | 点「中断」：当前这只跑完就停，已完成的报告都会保留 |
| 荐股报「所选板块没有取到任何数据」 | 东财接口不可用（限流或断网）、或所选细分名已变：稍后重试；点「刷新板块」重建缓存 |
| 荐股筛选区一直显示「板块数据加载中…」 | 首次加载要拉 31 个一级行业 + 504 个概念行情（约 1-2 秒）；失败时右侧会给出错误原文 |
| 展开行业看不到细分 | 该行业的成分股取数失败：看提示行（细分加载失败：…），点「刷新板块」或稍后重试 |
| 点「全选本页」没反应/提示上限 | 概念页全选受 120 个上限约束：先用搜索缩小范围再全选；行业页超过 6 个会先弹确认 |
| 模块按钮只能选一个 | 这是设计如此（单选）：要换权重就换模块；需要多模块结论目前只能分次跑 |
| 荐股只有板块、没有候选股 | 成分股取数失败或全被排除规则过滤：看页面「数据依赖与降级」逐条会写明；放宽排除规则或稍后重试 |
| 关掉自动刷新后不再出现新的到价消息 | 到价判定需要实时价：关掉自动刷新时，点一次「刷新实盘价」或打开自动刷新才会产生新消息 |
| 想看历史到价消息 | 顶栏铃铛（未读数）或控制台「消息队列」卡；落盘在 `data/ai/alerts.jsonl`，「清空」会二次确认并截断文件，不可恢复 |
| 自动刷新显示「已暂停：非交易时段」 | 正常行为：只在集合竞价与盘中自动取数，避免非交易时段白发请求；手动「刷新实盘价」随时可用 |
| 分时图显示「未取分时」 | 还没点「刷新实盘价」、也没开自动刷新：默认用本地口径价格，不联网取分时 |
| 刷新变慢或提示「连续失败 N 次，已退避」 | 行情接口被限流或断网：程序自动按 2 倍退避（最长 5 分钟），恢复后回到所选档位；也可手动点「刷新实盘价」重试 |
| 实盘复核显示「最近收盘价」「昨收」 | 非交易日或还没开盘：这是真实口径，不是 bug；盘中会变成实时价 |
| 实盘复核提示「已降级为 stock3d 缓存价 / 报告内现价」 | 东财实时行情取不到（限流或断网）：卡片会写明来源与时间，机械结论仍可用，点「刷新实盘价」重试 |
| 点「生成当前时段点评」后只有机械结论 | 模型调用失败：卡片会显示失败原因，产物仍落在 `data/ai/plancheck/`，不会掩饰成成功 |
| 回收站里的文件不见了 | 说明已超过 7 天被自动真删（回收站卡片会显示上次清理时间与删除数量），这类删除不可恢复 |
