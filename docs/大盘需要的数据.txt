### 2. 宏观流动性与政策数据（判断市场资金面与政策面）

#### 央行操作

- 当日重要会议 / 政策发布会：国务院、证监会、央行、部委发布会预告

### 3. 市场供给与消息面数据（判断当日风险点）

#### 市场供需

- 当日新股申购：数量、申购代码、募资总额、发行市盈率
- 当日新股上市：数量、上市板块

- 当日可转债申购 / 上市信息

#### 消息面分层

- 行业政策：工信部、发改委、能源局等发布的行业监管 / 扶持政策
- 个股公告：重点龙头股的业绩预告、重大合同、并购重组、大额减持、退市风险、监管问询等
- 前一交易日龙虎榜数据：机构买卖金额、知名游资席位动向、龙虎榜个股所属板块

## 二、盘中实时盯盘数据（9:30-15:00 跟踪）

### 1. 指数与量能数据（判断大盘强弱）

- 四大核心指数：上证指数、深证成指、创业板指、科创 50 的**实时点位、涨跌幅、振幅**
- 宽基风格指数：上证 50、沪深 300、中证 500、中证 1000 的实时涨跌幅（判断大盘 / 小盘风格）
- 两市实时总成交额：分沪市、深市单独统计，与前一交易日同期成交额对比（判断放量 / 缩量）
- 分时量价匹配：指数上涨 / 下跌时，成交量是否同步放大 / 缩小（识别量价背离）
- 分时均价线：指数在均价线上方为强，下方为弱

### 2. 市场情绪实时数据（判断赚钱效应）

- 涨跌家数：实时上涨家数、下跌家数、平盘家数，上涨个股占比
- 涨跌停数据：实时涨停家数、跌停家数（区分 ST），封单金额
- 炸板数据：实时炸板家数、炸板率 = 炸板数 ÷（涨停数 + 炸板数）
- 涨跌幅度分布：涨幅超 5% 个股数、跌幅超 5% 个股数
- 连板梯队：实时连板股总数、最高连板高度、各梯队（2 板 / 3 板 / 4 板及以上）数量
- 情绪标的走势：市场最高板、各板块龙头股、人气股的实时涨跌幅

### 3. 资金流向数据（判断主力动向）

- 北向资金：实时净流入 / 流出总额，分沪股通、深股通单独统计；每半小时净流入变化（判断流入持续性）
- 南向资金：实时净流入 / 流出总额
- 主力资金：两市主力资金实时净流入额，行业主力资金净流入 / 流出排名
- 板块资金：领涨 / 领跌板块的主力资金净流入额、成交额占比
- 个股资金：龙头股、人气股的主力资金净流入 / 流出

### 4. 板块轮动数据（判断主线与节奏）

- 行业板块实时涨跌幅排名（申万一级 / 二级）：领涨行业、领跌行业
- 概念板块实时涨跌幅排名：领涨概念、领跌概念
- 板块异动时间点：拉升 / 跳水的具体时间，对应消息面催化
- 板块内部结构：板块内涨停个股数、涨幅超 5% 个股数、龙头股涨幅（判断板块强度）
- 板块轮动速度：当日领涨板块与前一日的重合度（重合度低 = 轮动快，难操作）

### 5. 关键时点重点观察数据

#### 开盘定调期（9:30-10:00）

- 开盘后涨跌家数的延续性（竞价上涨家数是否维持）
- 开盘半小时成交额与前一日同期对比
- 主线板块开盘后是否放量延续，还是快速回落
- 龙头股开盘后的走势（溢价是否兑现、是否快速跳水）

#### 趋势验证期（10:00-11:30）

- 10:30 前后指数是否突破早盘高点 / 跌破早盘低点
- 突破时成交量是否同步放大（无量突破为假突破）
- 北向资金在 10:30 前后是否出现方向转向

#### 午后验证期（13:00-14:30）

- 午间消息对盘面的影响（开盘是否跳空）
- 上午趋势下午是否延续，是否出现量价背离
- 北向资金午后流向是否稳定，是否出现大幅波动

#### 尾盘定调期（14:30-15:00）

- 尾盘半小时成交额变化（是否放量）
- 涨跌家数尾盘是否出现批量异动（抢筹 / 砸盘）
- 北向资金尾盘流向（加速流入 / 流出 / 平稳）
- 板块尾盘异动：哪些板块尾盘放量抢筹 / 砸盘
- 收盘前涨跌停家数最终变化

- 最终涨跌家数：上涨家数、下跌家数、平盘家数，上涨占比

- 炸板数据：炸板总家数、全天炸板率
- 连板梯队数据：
  - 连板股总数
  - 最高连板高度
  - 各梯队数量：2 连板、3 连板、4 连板及以上
- 赚钱效应指标：全部 A 股平均涨幅、中位数涨幅

### 3. 全市场资金数据

- 北向资金：全天净流入 / 流出总额，沪股通 / 深股通分别净额；前十大成交股净买入 / 净卖出明细
- 南向资金：全天净流入 / 流出总额

- 龙虎榜数据：
  - 龙虎榜总成交额、机构席位净买入 / 净卖出总额
  - 知名游资席位买卖动向
  - 龙虎榜个股所属板块、涨停原因分类
  - 机构净买入个股名单、机构净卖出个股名单

### 4. 板块与题材复盘数据

- 行业板块排名：申万一级行业涨跌幅 TOP5、涨跌幅后 5 名；各行业成交额、资金净流入
- 概念板块排名：热门概念涨跌幅 TOP10；领涨概念的催化逻辑（政策 / 业绩 / 消息 / 外围）
- 板块强度评估：
  - 板块内涨停个股数、涨幅超 5% 个股数
  - 板块龙头股涨幅、连板高度
  - 板块成交额占两市总成交额的比例
- 板块持续性：近 3 个交易日领涨板块变化，主线板块的延续天数
- 领跌板块分析：下跌逻辑（利空消息 / 获利了结 / 估值调整）

### 5. 个股与交易复盘数据

- 人气股清单：成交额 TOP20、换手率 TOP20、振幅 TOP20 个股

- 涨跌停个股名单：涨停原因分类（政策驱动、业绩驱动、题材炒作、重组并购、次新等）
- 个人持仓复盘：每只持仓股的涨跌幅、量比、换手率、资金流向；是否符合盘前计划；盈亏原因分析

### 6. 次日前瞻预备数据

- 次日新股：申购数量 / 上市数量、募资总额、重点个股
- 次日限售解禁：解禁总市值、大额解禁个股名单、解禁类型
- 晚间公告汇总：重点公司业绩、重大事项、政策文件、行业消息
- 外围晚间走势：美股实时走势、A50 夜盘走势、大宗商品晚间波动
- 次日重要事件：经济数据发布、政策会议、行业活动预告
