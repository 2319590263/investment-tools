### 一、基本面数据清单

#### 1. 核心财务数据

**利润表核心**

- 营业总收入、营业收入同比增速、环比增速
- 归母净利润、净利润同比增速、环比增速
- 扣除非经常性损益净利润、扣非增速
- 毛利率、净利率、扣非净利率
- 期间费用率（销售 / 管理 / 研发 / 财务费用率）
- 非经常性损益金额及占净利润比例

**资产负债表核心**

- 总资产、总负债、资产负债率
- 货币资金、交易性金融资产（类现金总额）
- 有息负债总额（短期借款 + 长期借款 + 应付债券）
- 货币资金 / 有息负债比值
- 应收账款、应收票据、应收账款周转天数
- 存货、存货周转天数、存货跌价准备
- 固定资产、在建工程、商誉规模
- 流动比率、速动比率

**现金流量表核心**

- 经营活动产生的现金流量净额
- 净现比（经营现金流净额 / 净利润）
- 营收现金含量（销售商品收到的现金 / 营业收入）
- 投资活动现金流净额、筹资活动现金流净额

**成长与盈利质量**

- 近 3 年营收复合增长率（CAGR）
- 近 3 年净利润复合增长率
- 近 3 年 ROE（净资产收益率）、ROIC（投入资本回报率）
- 连续 2-3 个单季度营收 / 利润增速环比变化

#### 2. 业务与行业数据

- 主营业务分产品 / 分地区的营收占比、毛利占比
- 核心产品的产能、产量、销量、市场占有率
- 所属申万一级 / 二级行业、细分行业分类
- 行业内可比公司名单及对应财务、估值数据
- 行业景气度指标（行业 PMI、销量增速、价格指数等）
- 公司行业地位梯队（绝对龙头 / 二线龙头 / 跟风标的）

#### 3. 估值数据

- 静态 PE、动态 PE、滚动 PE（TTM）
- PB（市净率）、PS（市销率）
- PEG（市盈率相对盈利增长比率）
- 近 3 年 / 5 年 PE-TTM 分位数、PB 分位数
- 同行业可比公司平均 PE、PB、PS
- 绝对估值参考（DCF 估值、分部估值结果，如有）

#### 4. 股东与治理数据

- 前十大股东名单、持股比例、较上期变动
- 控股股东、实际控制人性质（国资 / 民营 / 外资）
- 大股东股权质押比例、质押平仓线参考
- 机构持仓比例：公募基金持仓占比、北向资金持仓占比
- 最近一期机构持仓变动（加仓 / 减仓幅度）
- 限售解禁：未来 1/3/6 个月解禁规模、解禁类型、解禁股东
- 近期减持计划：股东名称、减持比例、减持时间区间
- 回购计划：回购金额区间、回购价格区间、当前回购进度

### 二、消息面数据清单

#### 1. 公司公告类数据

- 最新财报（年报 / 季报 / 半年报）、业绩预告、业绩快报
- 重大合同与订单：合同金额、占上一年度营收比例
- 产能与产品：扩产公告、新产品发布、技术突破公告
- 资本运作：并购重组方案、定增预案 / 进展、股权激励方案
- 股东动作：增持 / 减持公告、回购公告、分红送转公告
- 风险公告：监管问询函、立案调查、业绩下修、退市风险警示

#### 2. 行业与政策数据

- 国家级行业政策：产业规划、补贴政策、监管政策、指导意见
- 地方行业政策：地方性扶持措施、区域产业规划
- 行业高频数据：月度销量、产量、价格、库存、开工率
- 行业事件：行业大会、技术发布会、龙头公司重大动作
- 产业链上下游动态：上游原材料涨价 / 降价、下游需求变化

#### 3. 宏观与外围数据

- 宏观政策：央行货币政策（降息 / 降准 / 逆回购）、重大财政政策
- 重要经济数据：CPI、PPI、PMI、社融、工业增加值等
- 外围对应板块：美股同行业龙头股涨跌幅、对应板块指数涨跌幅
- 相关大宗商品：对应原材料 / 产品的期货价格涨跌幅

#### 4. 资金情绪数据

- 龙虎榜数据：买入 / 卖出前五席位，机构席位净买卖金额，知名游资席位动向
- 北向资金：持股数量、持股市值、近 1/3/5 日持仓变动
- 两融数据：融资余额、融券余额、近 1/3/5 日变动幅度
- 机构调研：近 1 个月调研机构数量、调研纪要核心内容
- 市场关注度：人气排名、成交量排名、换手率排名变化

### 三、技术面数据清单

#### 1. 趋势与结构数据

- 月线级别：长期趋势方向，重要支撑压力位，20 月 / 60 月均线位置
- 周线级别：中期趋势方向，5 周 / 10 周 / 20 周 / 60 周均线位置，周线形态
- 日线级别：短期趋势方向，5/10/20/60/120/250 日均线位置与排列
- 关键价位：历史高低点、近 1 年高低点、近期平台高低点
- 缺口位置：向上缺口、向下缺口，缺口类型（普通 / 突破 / 衰竭）
- 价格形态：底部形态、顶部形态、整理形态的识别与确认

#### 2. 量价数据

- 当日成交量、成交额、换手率
- 5 日 / 10 日 / 20 日 / 60 日均量线，当前量能与均量的比值（量比）
- 近 5/10/20 日量价配合情况（涨放量 / 跌缩量等）
- 关键位置量能：突破位成交量、跌破位成交量
- 阶段性量能：底部堆量、高位放量、缩量回调的幅度

#### 3. 筹码与换手数据

- 最新筹码分布：主要筹码峰价格、筹码峰集中度
- 获利盘比例、套牢盘比例
- 市场平均持仓成本
- 日换手率、5 日平均换手率、10 日平均换手率
- 筹码迁移：近 1 个月筹码峰移动方向（上移 / 下移 / 不动）

#### 4. 技术指标数据

- 均线系统：各周期均线数值、金叉 / 死叉状态、股价与均线的位置关系
- MACD：DIF/DEA 数值、红绿柱长度、顶背离 / 底背离、零轴位置
- KDJ：K/D/J 数值、超买超卖区间、金叉死叉状态
- RSI（相对强弱指标）：6 日 / 12 日 RSI 数值、超买超卖区间
- BOLL（布林带）：上中下轨位置、股价所处轨道位置
- 多周期指标共振情况：日线 + 60 分钟级别是否同步发出信号

#### 5. 分时与盘口数据

- 集合竞价：竞价涨跌幅、竞价成交量、竞价量比、封单金额（如涨停）
- 分时均价线：股价在均价线上方 / 下方的时长
- 分时量价：拉升放量 / 回落缩量，还是量价背离
- 盘口大单：单笔大单成交金额、买卖盘大单挂单情况
- 涨停 / 跌停盘口：封单金额、封单稳定性、开板次数
